Daotalent Service
======================

TL;DR
-----
HR data synchronization service via RabbitMQ for Laravel.

Install
-------

Install via composer

```
composer require daotalent/daotalent-service-single
```

Generate config file

```
php artisan daotalent:config
```

Generate migrations

```
php artisan daotalent:make
```

Start queue

```
php artisan daotalent:work
```

Usage
-----

```
php artisan daotalent:work
```
